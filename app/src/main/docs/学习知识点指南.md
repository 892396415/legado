## 一、架构设计 (5个)

### 1. MVVM 架构模式

**知识点说明**：
MVVM（Model-View-ViewModel）是一种成熟的 Android 架构模式，通过数据绑定实现 UI 与业务逻辑的分离。项目中使用 Lifecycle 组件（ViewModel、LiveData）来实现这一架构。

**关键文件**：
- `app/src/main/java/io/legado/app/base/BaseViewModel.kt` - ViewModel 基类
- `app/src/main/java/io/legado/app/ui/main/` - 典型 MVVM 使用示例

**学习要点**：
- ViewModel 的创建与生命周期管理
- LiveData 的观察者模式使用
- 数据绑定（ViewBinding）的使用

---

### 2. Clean Architecture 分层设计

**知识点说明**：
项目采用清晰的 Clean Architecture 分层：
- **ui 层**：Activities、Fragments、Custom Views
- **model 层**：业务逻辑、规则解析
- **data 层**：数据库操作、数据源
- **service 层**：后台服务

**关键文件**：
- `app/src/main/java/io/legado/app/ui/` - UI 层
- `app/src/main/java/io/legado/app/model/` - 业务模型层
- `app/src/main/java/io/legado/app/data/` - 数据层

**学习要点**：
- 理解各层的职责边界
- 层的依赖方向（外层依赖内层）
- 业务逻辑的抽取与复用

## 二、数据库 Room (5个)

### 6. Room 数据库配置与升级

**知识点说明**：
项目使用 Room 作为本地数据库，当前版本为 75。数据库配置包含自动迁移和手动迁移两种方式。

**关键文件**：
- `app/src/main/java/io/legado/app/data/AppDatabase.kt` - 数据库配置
- `app/src/main/java/io/legado/app/data/Callbacks.kt` - 迁移回调

**学习要点**：
```kotlin
@Database(
    entities = [Book::class, BookChapter::class, ...],
    version = 75,
    exportSchema = true
)
abstract class AppDatabase : RoomDatabase() {
    // 配置自动迁移
    companion object {
        val MIGRATION_1_2 = object : Migration(1, 2) { ... }
    }
}
```
- 数据库单例模式
- 迁移策略（自动迁移 vs 手动迁移）

### 7. Entity 实体类设计

**知识点说明**：
Room 使用 Entity 注解来定义数据库表结构。

**关键文件**：
- `app/src/main/java/io/legado/app/data/entities/Book.kt` - 书籍实体
- `app/src/main/java/io/legado/app/data/entities/BookChapter.kt` - 章节实体
- `app/src/main/java/io/legado/app/data/entities/BookSource.kt` - 书源实体

**学习要点**：
```kotlin
@Entity(tableName = "books")
data class Book(
    @PrimaryKey
    val bookUrl: String,
    val name: String,
    val author: String,
    val coverUrl: String?,
    // 索引注解提高查询效率
    @Index(value = ["name", "author"])
    val searchKey: String?
)
```
- @Entity、@PrimaryKey、@Index 注解使用
- 复杂类型的转换（TypeConverter）
- 关系型数据设计（@Relation）

### 8. DAO 数据访问层

**知识点说明**：
DAO（Data Access Object）封装了数据库的 CRUD 操作。

**关键文件**：
- `app/src/main/java/io/legado/app/data/dao/BookDao.kt` - 书籍 DAO
- `app/src/main/java/io/legado/app/data/dao/BookChapterDao.kt` - 章节 DAO
- `app/src/main/java/io/legado/app/data/dao/BookSourceDao.kt` - 书源 DAO

**学习要点**：
```kotlin
@Dao
interface BookDao {
    @Query("SELECT * FROM books ORDER BY latestUploadTime DESC")
    fun observeAll(): Flow<List<Book>>

    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun insert(book: Book)

    @Update
    suspend fun update(book: Book)

    @Delete
    suspend fun delete(book: Book)

    @Query("DELETE FROM books WHERE bookUrl = :bookUrl")
    suspend fun deleteByUrl(bookUrl: String)
}
```
- @Query 复杂查询
- @Insert、@Update、@Delete 操作
- Flow 响应式数据
